PROBLEM

Read a positive integer n, then compute and print the sum of all integers from 1 to n.

Input

One line: a positive integer n. (Provide it in the Input box on the right, one value per line.)

Output

One line: the sum from 1 to n.

Example

Input
100

Output
5050
